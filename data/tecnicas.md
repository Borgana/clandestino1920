Técnicas de Coctelería — Clandestino 1920
Stirred (Removido)
Uso: cócteles solo destilados (Old Fashioned, Negroni, Manhattan, Dry Martini)
Herramienta: vaso mixing + cuchara bar + hielo grande
Objetivo: enfriar + diluir controlado + textura sedosa sin aire
Tiempo: 20-30 seg / ~50 vueltas
Strain: colador fino (double strain si hay hierbas/hielo pequeño)
Shaken (Agitado)
Uso: cócteles con cítricos, jarabes, claras, lácteos, cremas (Whisky Sour, Daiquiri, Espresso Martini)
Herramienta: shaker tin-on-tin + hielo
Hard shake: 10-12 seg vigoroso → textura, emulsión, microburbujas
Strain: double strain (colador Hawthorne + colador fino)
Muddled (Machacado)
Uso: Mojito, Caipirinha, Old Fashioned (azúcar + bitters)
Herramienta: mortero/muddler
Regla: presionar suave, NO destrozar (hierbabuena → aceites, no clorofila amarga)
Fat-wash (Lavado en grasa)
Uso: bourbon con mantequilla tostada, gin con aceite sésamo, ron con coco
Proceso: mezclar destilado + grasa líquida → reposo 2-4h → congelar → retirar grasa sólida → filtrar café
Aporta: cuerpo, boca untuosa, notas tostadas/lácteas
Clarificado (Milk punch / Agar)
Uso: cócteles ácidos/lácteos claros (Milk Punch, Piña Colada clarificada)
Milk punch: añadir leche a cóctel ácido → cuaja → filtrar tela/café → líquido transparente, sedoso, estable
Agar-agar: gelificar → romper gel → centrifugar/filtrar → consomé cristalino
Double Strain / Fine Strain
Siempre que: hierbas, fruta, clara, especias, hielo pequeño
Hawthorne (resorte) + colador fino malla → nada de "hielos" en copa
Hielo
Cubo grande (5x5cm) → stirred, rocks → dilución lenta
Hielo picado → shaken, juleps, tiki → enfriado rápido
Esfera → Old Fashioned premium, whisky solo
Garnish / Decoración
Twist naranja/limón: aceites sobre copa + bordear
Hierbas: palmada entre manos (despierta aceites) + clavar
Deshidratadas: rodajas cítricos horno 80°C 2-3h
Humo: smoking gun / antorcha + tabla madera → cloche
